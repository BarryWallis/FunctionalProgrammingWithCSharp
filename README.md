# FunctionalProgrammingWithCSharp
Code from the Packt Publishing book "Functional Programming with C#". 
The code is organized in folders by chapter, and each folder contains the code examples for that chapter. 
The code is written in C# and uses .NET Core. 
The code is intended to be used as a reference for the concepts and techniques covered in the book.

I have updaeted and annotated the code examples for my own edification. Any mistakes introduced are mine and not the author's.
